# 源码模块速查：Sub2API backend/

**编制日期**：2026-05-07
**用途**：快速定位 Sub2API 后端各模块的源码文件

---

## 1. 目录结构概览

```
backend/
├── cmd/server/          # 入口 main.go
├── ent/                 # ORM Schema 定义（对应数据库表）
│   ├── schema/          # Schema 文件（account.go, api_key.go 等）
│   ├── account.go       # 生成的 Account ent client
│   └── ...              # 其他生成的 ent client
├── internal/
│   ├── config/          # 配置加载
│   ├── domain/          # 领域常量（Platform, Status 等）
│   ├── handler/         # HTTP Handler
│   │   ├── admin/       # 管理后台 Handler
│   │   ├── auth_handler.go      # 登录/注册/OAuth
│   │   ├── gateway_handler.go    # OpenAI 网关（代理转发核心）
│   │   ├── openai_gateway_handler.go  # OpenAI 协议处理
│   │   ├── payment_handler.go    # 支付/充值
│   │   ├── redeem_handler.go     # 兑换码
│   │   ├── api_key_handler.go    # API Key 管理
│   │   ├── user_handler.go       # 用户管理
│   │   ├── usage_handler.go      # 用量查询
│   │   └── subscription_handler.go # 订阅管理
│   ├── service/         # 业务逻辑层
│   ├── repository/      # 数据访问层
│   ├── server/          # HTTP 服务器
│   │   └── routes/      # 路由定义
│   │       ├── admin.go
│   │       ├── auth.go
│   │       ├── user.go
│   │       ├── gateway.go
│   │       └── payment.go
│   └── web/             # 前端嵌入
└── migrations/          # 数据库迁移
```

## 4. 关键路由速查

| `POST /api/auth/logout` | `auth_handler.Logout` | 登出 |
| `GET /v1/chat/completions` | `gateway_handler.HandleChatCompletions` | **核心代理接口** |
| `POST /v1/chat/completions` | `gateway_handler.HandleChatCompletions` | **核心代理接口** |
