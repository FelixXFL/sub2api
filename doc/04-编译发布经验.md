**日期**：2026-05-08
**类型**：经验总结

## 问题一：前端未嵌入二进制

### 现象
编译后部署，访问返回 `404 page not found`，但后端 API 正常。

### 根因
Nexus 使用 Go embed 机制嵌入前端资源，编译时**必须**加 `-tags=embed` 标签。

```bash
# ❌ 错误：没有 embed 标签，前端未嵌入
go build -o nexus ./cmd/server

# ✅ 正确：带 embed 标签
go build -tags=embed -o nexus ./cmd/server
```

Makefile 的 build 目标已修复为包含 `-tags=embed`。

### 预防
- **必须用 `make build`**，禁止直接 `go build`
- Makefile 已内置正确参数

## 问题二：Setup Wizard 无法跳过

### 现象
数据库已有数据，但访问 `/setup/status` 返回 `needs_setup: true`，每次都弹出安装向导。

### 根因
`NeedsSetup()` 检查数据目录下的配置文件和锁文件：
- `/opt/nexus/config.yaml`
- `/opt/nexus/.installed`

但进程工作目录不是 `/opt/nexus` 时，查找路径错误，导致误判需要 setup。

### 解决
启动时设置 `DATA_DIR` 环境变量：

```bash
# ❌ 错误：从其他目录启动
./current
cd /some/where && ./current

# ✅ 正确：设置 DATA_DIR
DATA_DIR=/opt/nexus /opt/nexus/current

# ✅ 或使用 systemd（自动配置环境变量）
systemctl restart nexus
```

### 验证
```bash
# 检查进程工作目录
lsof -p <PID> | grep cwd

# 检查 needs_setup 状态
curl http://localhost:8080/setup/status
# 期望：{"needs_setup": false}
```
